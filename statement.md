# Hostel Finance Manager — Project Statement

## 1. Problem Statement

College students living in hostels often have to manage money received through pocket money, scholarships, part-time work, or other sources while also handling regular expenses such as food, education, travel, hostel requirements, entertainment, technology, and personal needs.

When these financial activities are tracked manually or in an unorganized manner, students may find it difficult to:

- Keep a proper record of income and expenses.
- Understand where their money is being spent.
- Calculate their current available balance.
- Control spending within predefined budgets.
- Track progress toward savings goals.
- Find previous transactions quickly.
- Keep track of recurring expenses.
- Analyze their financial activity for a particular month.

The **Hostel Finance Manager** is developed to provide a structured and simple solution for managing these financial activities.

The application allows students to record and organize their financial transactions, calculate their balance, manage budgets and savings goals, search transactions, maintain recurring expenses, generate monthly reports, and view a consolidated financial dashboard.

---

## 2. Scope of the Project

The scope of the Hostel Finance Manager is focused on providing a local, student-oriented personal finance management system.

The project includes the following areas:

### Financial Transaction Management

The system allows users to:

- Add income transactions.
- Add expense transactions.
- Categorize expenses.
- Record payment methods.
- View previously recorded transactions.

### Financial Analysis

The system processes stored financial data to provide:

- Total income.
- Total expenses.
- Current balance.
- Savings percentage.
- Category-wise expense information.
- Monthly financial summaries.

### Budget Management

Users can:

- Set category-wise budgets.
- Update budgets.
- View budget status.
- Compare spending with the allocated budget.

### Savings Management

Users can:

- Create a savings goal.
- Set a target amount.
- View current savings.
- Track progress toward the savings target.

### Transaction Search

Users can search stored transactions using:

- Transaction type.
- Category.
- Payment method.
- Description keyword.
- Minimum amount.

### Recurring Expense Management

Users can:

- Add recurring expenses.
- View recurring expenses.
- Delete recurring expenses.
- Specify recurring frequency and due dates.

### Student Profile Management

The system stores basic student information such as:

- Name.
- College.
- Course.
- Academic year.
- Hostel.
- Room number.
- Monthly allowance.

### Monthly Reporting

The system can generate a report for a selected month and year containing:

- Monthly income.
- Monthly expenses.
- Monthly balance.
- Savings rate.
- Category-wise spending.
- Transaction counts.

### Financial Dashboard

The dashboard provides a consolidated view of available financial information, including:

- Student profile.
- Income.
- Expenses.
- Balance.
- Category-wise spending.
- Budget status.
- Savings goal.
- Recurring expenses.

### Data Storage

The application uses local file-based storage:

- CSV for financial transaction records.
- JSON for budgets, savings goals, recurring expenses, and student profile information.

The current scope does not include online banking integration, cloud synchronization, or a web/mobile interface.

## 3. Target Users

The primary target users of the Hostel Finance Manager are:

### College Students

The application is primarily designed for college students who want to organize and monitor their personal finances.

### Hostel Students

The project is particularly relevant to students living in hostels because they commonly manage multiple categories of day-to-day expenses such as:

- Mess and food.
- Travel.
- Hostel requirements.
- Education.
- Entertainment.
- Personal expenses.
- Technology.
- Sports and fitness.

### Students Managing Personal Budgets

Students who receive a fixed monthly allowance or manage money from scholarships, part-time work, freelancing, or other sources can use the application to monitor their spending and savings.

## 4. High-Level Features

The major features of the Hostel Finance Manager are:

1. **Income Management**  
   Record and organize different sources of student income.

2. **Expense Management**  
   Record expenses using categories and subcategories.

3. **Transaction Management**  
   View stored financial transactions and financial totals.

4. **Balance Calculation**  
   Calculate total income, total expenses, current balance, and savings percentage.

5. **Budget Management**  
   Set and monitor category-wise spending budgets.

6. **Savings Management**  
   Create savings goals and monitor savings progress.

7. **Monthly Financial Reports**  
   Generate financial summaries for a selected month and year.

8. **Transaction Search**  
   Search transactions using multiple criteria.

9. **Recurring Expense Management**  
   Store and manage regular expenses with different frequencies and due dates.

10. **Student Profile Management**  
    Store basic student and hostel-related information.

11. **Financial Dashboard**  
    View important financial information in a consolidated format.

12. **Local Data Storage**  
    Store transaction data using CSV and other application information using JSON files.

---

## 5. Project Goal

The overall goal of the project is to provide college students with a simple and structured way to manage their personal finances while demonstrating the practical application of Python programming concepts such as modular programming, functions, file handling, data processing, validation, searching, and report generation.
